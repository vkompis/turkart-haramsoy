# Turkart Haramsøy

Interaktivt turkart for Haramsøya, laga for Haramsøy idrettslag.

Vel ein tur i lista for å sjå ruta animert på kartet, med lengd, stigning, tid og høgdeprofil.
Klikk på ein sti for å sjå kva turar som går der.

**Kartet:** https://vkompis.github.io/turkart-haramsoy/

## Filer

- `index.html` – sjølve kartet (Mapbox GL JS)
- `data.js` – turar, stiar, turmål, parkering og fasilitetar. Lagast av `skript/lag_webdata.py` frå `turkart.gpkg`.
- `ikon.js` – ikona, same som på det trykte turkartet
